Usage-Based Billing

Tokens, Credits, and USD

A high-level explanation of how usage is measured, how providers translate that usage into credits, and how credits map back to USD.

01 — The Basics

What is a token?

Token

Smallest billing unit for text

AI models typically count text in tokens, not words. A token may be a whole word, part of a word, punctuation, or even a space.

Input

What you send

Prompts, system instructions, and retrieved context all consume input tokens.

Output

What the model returns

The model’s response is counted separately as output tokens, which are often priced differently from input tokens.

Rule of thumb: more text usually means more tokens, but the exact count depends on how the text is split by the model’s tokenizer.
02 — Usage Measurement

How tokens relate to credits

Tokens used → converted to usage cost

Provider billing starts with token counts. The platform applies the model’s rate to those tokens.

Usage cost → converted to credits

Some platforms show the cost as internal credits. Credits are a display or accounting layer, not usually a new kind of usage.

Credits → deducted from balance

Your balance decreases as credits are spent, and those credits represent the underlying usage charge.

Important: credits are often just a billing abstraction. They make usage easier to present, but the underlying source of truth is still token usage and the provider’s pricing.
03 — Billing Conversion

How credits relate to USD

USD is the real currency value

Pricing is ultimately defined in dollars per token, per million tokens, or another USD-based rate.

Credits mirror that value

One credit may equal one cent, one dollar, or some other fixed amount depending on the product.

Conversion is product-specific

The exact credit-to-USD ratio is set by the platform and can differ across plans, models, or billing systems.

In practice: tokens determine usage → usage becomes a dollar cost → the platform may show that cost as credits → credits map back to USD.
04 — Simple Formula

A high-level billing flow

Common mental model

Usage-based billing usually follows this pattern:

Tokens used × model price = USD cost → credits deducted
This is a simplification. Actual invoices may also include separate pricing for input vs. output tokens, tool use, image generation, or other features.
05 — Key Takeaway

Tokens are the usage meter

At a high level, tokens measure how much text a model processes. Credits are a billing layer that helps platforms track and show that usage. USD is the monetary value underneath it all. So if you want to estimate cost, start with token usage, apply the model’s rate, and then convert to credits or dollars depending on how the platform presents billing.
